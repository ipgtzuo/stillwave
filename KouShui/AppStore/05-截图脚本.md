# 截图规格与拍摄脚本

> **重要**：Apple 会随新硬件更新截图规格，且 2026 年不同资料对「iPhone 必填集合」的表述不一致。
> 上传前一定以 App Store Connect → Screenshot Specifications 页面当时显示为准。
> 本表核实于 2026-11-08；采取的是**多传一套**的稳妥策略，而不是赌某一套。

---

## 1. 规格速查

| 货架 | 尺寸（竖屏 px） | 是否必填 | 本工程做法 |
|---|---|---|---|
| iPhone with Dynamic Island（medium） | 1206 × 2622 或 1179 × 2556 | 多数资料列为必填 | ✅ 传 1206 × 2622 |
| iPhone with Dynamic Island（large，原 6.9″） | 1260 × 2736 / 1290 × 2796 / 1320 × 2868 | 部分资料列为必填 | ✅ 再传 1320 × 2868，规避歧义 |
| iPad 13″ | 2064 × 2752 | 仅当 App 支持 iPad | ⛔ 不需要：工程已设 `TARGETED_DEVICE_FAMILY = 1` |
| Apple Watch | 422 × 514；也接受 410 × 502 / 416 × 496 / 396 × 484 / 368 × 448 / 312 × 390 | Watch App 必填 | ✅ 统一用 422 × 514，**所有本地化用同一尺寸** |
| iPhone Duo | 外屏 1398 × 2034 / 内屏 2007 × 2853 | Apple 公告 2027 年 4 月起对 iOS 27.1+ SDK 提交强制；ASC 现已接受 | 若 ASC 标记缺失则补；本工程 SDK 27.2，留意 |

其他规则：
- 格式 PNG / JPEG，**无 alpha 通道**、sRGB；每一个尺寸 **1–10 张**。
- Apple Watch 的截图在 **ASC 的 Apple Watch 标签页**单独上传，不能复用 iPhone 货架。
- 截图必须展示真实运行界面，不能纯文字 marketing 图（Apple 会扫「无 UI 内容」）。
- 所有本地化（zh-Hans / en-US）都要有对应截图；文案也要跟着本地化。

## 4. 拍摄步骤

### 真机（推荐，触觉与色彩最可信）
1. iPhone + Apple Watch 都装 TestFlight 版本，关闭「自动亮度」，设深色/浅色各一套。
2. 截图前把状态栏整理干净（时间统一 9:41、满电、无通知）：Xcode → `xcrun simctl status_bar` 仅对模拟器有效；真机用「快捷指令」或后期裁切。
3. 按上面构图手动敲出状态；**回想态要停手等 3–5 秒再截**。
4. 用 `sips -g pixelWidth -g pixelHeight -g hasAlpha` 确认导出无 alpha；按货架尺寸精确缩放，不要差 1 px。

### 模拟器（补尺寸用）
```bash
# 列出可用设备
xcrun simctl list devices available | grep -iE 'iPhone|Apple Watch'

# 启动、安装、清理状态栏、启动 App
xcrun simctl boot <UDID>
xcrun simctl install booted /tmp/koushui-dd/Build/Products/Debug-iphonesimulator/Stillwave.app
xcrun simctl status_bar booted override --time 9:41 --batteryState charged --batteryLevel 100 --wifiBars 3 --cellularBars 4
xcrun simctl ui booted appearance dark
xcrun simctl launch booted com.example.koushui
xcrun simctl io booted screenshot /tmp/koushui-shot.png
```

⚠️ 两个限制：
- 模拟器**没有触觉**，也无法用 `simctl` 直接模拟点击。要拍「连敲 / 回想」态，用 Xcode UI Test 驱动 `XCUIApplication().tap()`，或在 **DEBUG 编译条件**下加一个仅供截图的 `UIScene` 启动参数自动播放演示——**务必用 `#if DEBUG`，不要进 Release 包**，否则会踩 2.3.1 隐藏功能。
- 模拟器截出来的尺寸未必等于货架尺寸，用 `sips -z H W` 精确重采样并校验无 alpha。

### 从本工程生成主视觉
```bash
cd .. && python3 make_icons.py    # 图标 + icon-preview.html
```
`icon-preview.html` 里已有商店卡片 / 主屏 / 表盘三种尺寸的内联 SVG，可直接作为推广物料的版式参考。

## 5. 已生成的首屏示例

`screenshots/iphone-01-home.png` / `iphone-01-home.jpg` 是**从本次编译产物在 iPhone 17 模拟器里真实启动截取的首屏**，1206 × 2622，正好是 medium Dynamic Island 货架尺寸。

- `.png` 用于预览（模拟器截图自带 alpha）；`.jpg` 已 flatten，**无 alpha 通道**，可直接上传。
- 这一步顺带发现并修好了两处真机也会踩的 plist 问题（见 `03-发布流程.md`）：Watch Info.plist 必须有 `WKApplication = true` 与 `WKCompanionAppBundleIdentifier`，否则整个 iOS 包安装被拒。
- 首屏原本几乎全黑（水面线条透明度 0.08–0.16），已把环境水纹提到 0.17–0.34、文字提到 0.4–0.62，观感在模拟器中确认可辨。
- **其余 5 张 iPhone 与 3 张 Watch 截图仍需真机或 UI Test 驱动交互**（`simctl` 没有点击命令），尤其第 2 张「连敲成句」与第 3 张「水在回想」。切勿用设计稿代替实截。
- 模拟器首帧渲染较慢，`simctl launch` 后要等 App 真正进前台再截（可直接再 `simctl launch` 一次激活）；过早截会得到全黑帧。
