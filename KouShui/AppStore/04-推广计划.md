# 推广计划 · 叩音 / Stillwave

> 一句话定位：**压力上来那一刻，不用看屏幕、不用戴耳机、不用做对任何事，敲完 30 秒就走。**
> 卖点不是「功能多」，是「对的时间被用了一次」。别用下载量或 DAU 判断这个品类的成败。

---

## 1. 目标人群（按优先级）

| 人群 | 场景 | 最该打的一句话 |
|---|---|---|
| 戴 Apple Watch 的通勤 / 开会族 | 静音场合、不想被看见在「做冥想」 | 「腕上不出声，也能敲完一句」 |
| 对国风 / 声音质感敏感的人 | 夜里、书桌前，愿意戴耳机听 | 「三分损益律的五音，一池有记忆的水」 |
| 轻度情绪管理用户（非临床） | 被「压力分数」类 App 劝退过 | 「不打分、不排行、不提醒你坚持」 |
| 独立 App / 设计审美向媒体 | 找有想法的中国独立作品 | 「一笔墨符、一句旋律、一次回想」 |

明确**不追**：需要课程、打卡、连续记录、睡眠监测、医学疗效的用户。这些人进来会失望，也会拉低评分。

---

## 2. ASO（先做免费的）

- **名称**：`叩音` / `Stillwave`（已定名，无谐音歧义）。所有口播、视频字幕、落地页统一用这两个写法；上架前仍需 ASC 查重。
- **副标**：`一叩一应 · 腕上的片刻安静` 承担「这是什么」；英文 `A knock, a wave, stillness` 承担调性。
- **关键词**：见 `01-商店文案.md`，中英各 97/99 字节。别塞竞品名、别重复名称里已有的字、别加空格（空格也算字节）。
- **图标**：深色墨池主版在深色模式商店页对比度偏低，用 `app-icon-paper-1024.png`（宣纸浅色）做一次 A/B 测试（ASC 产品页优化，可同时跑 3 个处理）。
- **前 3 张截图决定转化**：必须展示「敲 → 句子 → 回想」这条机制，而不是只放一张好看的水面。详见 `05-截图脚本.md`。
- **本地化**：首版 zh-Hans + en-US；若日语/繁中市场有自然量再加，别一次铺太多。
- **评分**：App 内不弹评分弹窗（会打断沉浸）。可在「关于」页放一行极淡的「喜欢的话，去商店留个评分」。

## 3. 内容素材包（一次做完，全渠道复用）

**主视觉 3 张**（用 `make_icons.py` 与 `icon-preview.html` 的同一套视觉语言）
1. 一枚叩点 + 一整片连续水线（图标放大版，无字）→ 封面 / 头像。
2. 五笔五行墨符横排，配「宫土 商金 角木 徵火 羽水」→ 讲设计细节。
3. Apple Watch 表盘上的「叩音 · 12 · 静音」+ 熄屏触觉节奏示意 → 讲腕上不发声。

**15 秒竖屏无声视频脚本**（无声！因为主题就是「不出声也完整」）
| 秒 | 画面 | 字幕 |
|---|---|---|
| 0–2 | 全黑，一枚指腹轻触水面 | 「不用打开任何东西」 |
| 2–6 | 连续 4 下，水纹叠加，墨符依次浮起 | 「连敲成句」 |
| 6–9 | 停手，画面慢下来、色调转冷 | 「然后，什么也不做」 |
| 9–13 | 水把那一句更淡地还回来 | 「水会回想」 |
| 13–15 | 归于静，出 Logo + App Store 字样 | 「叩音 · 一叩一应」 |

**一句 slogan 备选**：
- 「一叩一应，归于静。」
- 「不用戴耳机，也不用做对。」
- 「压力上来的时候，它已经在手腕上。」

## 4. 渠道与节奏（不花钱优先）

| 时点 | 渠道 | 动作 | 物料 |
|---|---|---|---|
| T-14 | 私域 / 朋友圈 / 即刻 | 招募 20–30 个戴表的人进 TestFlight，只问一句：「压力上来时你会主动点开吗？」 | TF 链接 + 3 个问题 |
| T-10 | 小红书 | 图文：「我给自己做了一池不会出声的水」——讲腕上静音的取舍，不列功能清单 | 主视觉 1 + 3 张截图 |
| T-7 | 即刻 / V2EX / 少数派投稿 | 技术向：「watchOS 调不了触觉强度，于是我把曲调搬到了节奏上」 | 波场示意 + 触觉乐谱图 |
| T-3 | B 站 / 视频号 | 15 秒无声视频 + 30 秒带耳机版（展示五音） | 视频脚本 |
| T-0 | X / Product Hunt（英文） | Stillwave 发布贴，主打 "sound-off by default on Apple Watch" | 英文描述 + 视频 |
| T+1 | 设计/独立开发类媒体邮件 | 10–20 封个性化短邮件，附「为什么不做压力分数」的一页说明 | 主视觉 + 一段话 |
| T+7 | 社区复盘 | 公开首周真实数据（不美化），回评论 | 数据图 |
| T+30 | 版本 1.1 | 根据反馈只做一件事（最可能是「让位幅度」或「宣纸亮度」） | 更新说明 |

**KOL / 投放**：第一版不建议投信息流。这类产品的价值靠「被一个人认真推荐」，不靠曝光量。预算若有，优先给 3–5 个真的戴表、真的写使用感受的中小创作者，而不是大号。

## 5. 首月看什么指标（别看 DAU）

| 指标 | 为什么 | 目标（自定基线即可） |
|---|---|---|
| 完成一次会话数 / 安装 | 有没有真的被用起来 | 首周 ≥ 60% |
| 「回想」触发率 | 用户愿不愿意停手等那 3 秒，是沉浸感最硬的证据 | ≥ 35% |
| 第 7 日回访 | 是「一次性好奇」还是「压力时刻会回来」 | ≥ 20% |
| Watch 端会话占比 | 双端是否都成立 | ≥ 30%（戴表用户中） |
| 评分与评论关键词 | 有没有出现「安静」「不打扰」「开会」这些我们想占的词 | 4.5+ |
| 卸载后评论里的负面主题 | 最常见会是「没声音」「看不懂」 | 逐条归类，进 1.1 |

**注意**：第一版没有埋点、不收集数据，上面这些指标要么靠 App Store Connect 的下载/评分，要么靠 TestFlight 用户主动反馈与问卷。别为了看数把隐私优势丢了——真要测，先更新隐私政策与 PrivacyInfo 声明。

## 6. 推广合规红线

- 不写「缓解焦虑」「改善睡眠」「降低血压」「调理五脏」「五音疗疾」，**包括视频字幕、口播、评论区回复**。
- 不做「你有压力吗」式焦虑营销；语气是「想安静一会儿的时候」，不是「你快撑不住了」。
- 不暗示医疗或健康监测能力；不把「五行墨符」讲成养生功能。
- 不承诺「 scientifically proven / 临床验证」之类说法。
- 不伪造评论、不刷榜、不买量诱导。
