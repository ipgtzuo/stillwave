## 审核备注（直接粘贴到 App Store Connect → App 审核信息 → 备注）

```
这是一个 30–60 秒的正念 / 自我关怀小练习：用户轻敲屏幕，App 播放一段五音旋律与触觉节奏；停手约 3 秒后，把刚才那一句更轻地回放一次。

审核要点：
1) 无需登录、无账号、无服务器、无网络请求，因此没有演示账号。所有功能打开 App 即可使用，没有隐藏功能或需要审核员额外操作才能触发的路径。
2) Apple Watch 端声明了 WKBackgroundModes: mindfulness。它只用于「放下手腕、屏幕熄灭后继续播放触觉节奏」这一种正念练习，时长通常 30–60 秒，不用于常驻后台、定位、音频串流或数据采集。声音默认关闭，因此没有使用 background audio 模式。
3) 第一版完全不接入 HealthKit，不读取心率、不写健康数据，也没有任何健康数据披露。
4) 不收集任何用户数据，无追踪、无第三方 SDK、无广告、无 App 内购买。两个 target 均包含 PrivacyInfo.xcprivacy，声明空数据类型。
5) 文案不含治疗、缓解焦虑、改善睡眠、降低血压、调理脏腑等任何疗效宣称；五行墨符仅是视觉符号，与养生主张无关。
6) 建议体验方式：进入 App 后连续轻敲 4–6 下，然后停手等待约 3–5 秒，可看到/听到「水在回想」。在 Apple Watch 上放下手腕，触觉仍会继续。
7) 关于技术架构：界面在一个内嵌的 WKWebView 中呈现，这是应用自身的体验的一部分（全部资源打包在 App 内，不加载任何外部网页、不做任何网络请求）；触觉由原生 Core Haptics 引擎按四种材质参数实时驱动，音频会话、后台与静音策略均为原生实现。选择该架构是为了让水面渲染与动效逐帧一致，并非功能最小化的壳应用。

谢谢！
```

## 支持页全文（Support URL）

```
叩音 · 支持

Q：为什么没有声音？
A：这是设计，不是故障。尤其在 Apple Watch 上，声音默认关闭——开会、通勤、夜里都不该突然出声。曲调改由最轻的触觉节奏承载。想听五音，请在 iPhone 端「调」里打开「播放五音」。

Q：需要戴耳机吗？
A：不需要。戴上耳机，回响会更远、更有空间感，但那只是增益。腕上、静音、熄屏时，App 都是完整的。

Q：放下手腕后还能用吗？
A：可以。Watch 端用 mindfulness 会话在熄屏后继续播放触觉节奏，通常够敲完 30–60 秒的一句。勿扰 / 专注模式下系统会连触觉一起关闭，App 不会绕过，也不会弹窗。

Q：为什么震动感觉都一样？
A：Apple Watch 的触觉只有 9 个系统预设，开发者不能调强度或自定义波形。我们用「两下轻拍之间的疏密」来表达音高，音越高越密。iPhone 端可以用 Core Haptics 真正调柔软度（云朵 / 水面 / 软木 / 绒布）。

Q：水会把刚才的句子再放一遍，是循环播放吗？
A：不是。一次回想，之后归于静。中途再敲会打断它，另起一句。

Q：会耗电吗？
A：水面动画在 Watch 端限制到 24fps，且只在本次练习期间持续。若仍觉得耗电，可在「调」里把「动静」调低。

Q：我的数据会被上传吗？
A：不会。详见隐私政策。

还有问题 / 想提建议：TODO your@email.com
```

## 常见拒审与对策

| 条款 / 拒审理由 | 触发点 | 对策 |
|---|---|---|
| 2.1 信息不完整 | 审核员不知道「回想」要等 3 秒 | 审核备注写清体验步骤；附 15 秒无声录屏 |
| 2.3.1 隐藏功能 | 五音、心境、景藏得太深 | 首次进入给一行极淡提示；所有入口都在当前页面可见 |
| 3.1.1 内购 | 未来若做「解锁全部景」 | 第一版不做；以后必须用 App 内购买，不能用外部支付或兑换码 |
| 4.2 最低功能 | 被判定为「只是一个按钮」；或被判定为「套壳网页」 | 描述里讲清有曲调的随机、回想、四心境、五景；截图展示不同状态。审核备注第 7 条已说明：WKWebView 只是界面呈现层（资源全部内置、零网络请求），触觉引擎 / 音频会话 / 后台策略均为原生实现。若仍被拒，退路是把 WebView 视觉换成原生 Canvas 重做（工程里 `Shared/` 的模型与墨符可直接复用） |
| 5.1.1 数据收集 | 隐私政策 URL 打不开 / 声明与实际不符 | 提审前实测 URL 200；若以后加 UserDefaults 持久化，须在 PrivacyInfo 里补 CA92.1 |
| 后台模式滥用 | mindfulness 被质疑常驻 | 备注写清 30–60 秒、不发声、熄屏触觉；**不要**同时勾 background audio |
| 截图与构建不符 | 截图是设计稿、App 实际不同 | 用模拟器/真机实截；浅色宣纸截图必须与景切换一致 |
| Watch App 图标缺失 | Watch target 没有自己的 AppIcon | 工程已放全套尺寸（11 个槽位），编译 0 warning |
| 医疗 / 疗效宣称 | 描述、截图文案、隐私页出现「缓解焦虑」「改善睡眠」 | 全站文案过一遍，只描述体验不承诺效果 |
| 名称 / 商标 | 「叩音」或 Stillwave 已被占用 | ASC 查重 + 商标检索；命名说明见 01-商店文案.md |
